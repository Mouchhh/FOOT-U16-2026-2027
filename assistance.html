Assistance

Mise à jour : 3 novembre 2026

Besoin d’aide ?

Pour un problème d’accès à votre compte, d’équipe, de document partagé ou une demande sur vos données, contactez Enzo MOUCHET — mouchetenzo@gmail.com.

Signaler un problème technique

Vous pouvez ouvrir un signalement sur le dépôt du site (compte GitHub nécessaire). Ce canal est public : ne joignez ni informations personnelles de joueurs, ni identifiants, mots de passe, clés ou secrets. Indiquez l’action effectuée, le message d’erreur exact, le navigateur et le type d’appareil. Masquez les données personnelles sur les captures.

Connexion Canva

Connectez-vous au site avec votre propre compte éducateur, ouvrez Match → Causerie, puis le cadre Mon Canva. Autorisez l’ouverture de la fenêtre de connexion et utilisez votre propre compte Canva. Si Canva affiche « L’ID du client est introuvable », transmettez ce message au responsable du site : il faut vérifier la configuration et les conditions d’accès de l’intégration Canva. Changer d’appareil ne garantit pas de résoudre cette erreur.

Présentation et PowerPoint

Le bouton PowerPoint situé à côté de « Causerie · Canva » permet de télécharger la causerie sans connexion Canva. Vous pouvez ensuite importer ce fichier dans votre compte Canva. Vérifiez le rendu avant utilisation.

Autorisation et sauvegarde

Pour retirer l’accès Canva, utilisez « Déconnecter Canva » et les réglages d’autorisation de votre compte Canva. Une déconnexion n’efface pas une présentation déjà créée dans Canva. Avant d’effacer le stockage du navigateur pour dépanner, exportez votre travail local : des brouillons pourraient être perdus.
