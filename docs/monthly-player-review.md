# Restitution mensuelle

Le rappel est projeté dans le calendrier au dernier jour du mois affiché (y compris février bissextile). En vue liste sans mois sélectionné, il concerne le mois courant. Il ouvre directement l’effectif et le mois correspondant, sans créer de séance, modifier un match ou envoyer une notification externe.

Le champ « Bilan mensuel des joueurs » sélectionne une période ; « Vue saison » rétablit les lignes habituelles. Les agrégats réutilisent le modèle statistique existant : équipe active, joueurs liés par identifiant, bilans enregistrés, dédoublonnage et exclusion des dates futures. Aucun total supplémentaire n’est stocké.

Le taux de présence mensuel utilise uniquement les pointages validés du mois : présents / (présents + absents). Les séances non pointées et statuts incertains restent hors dénominateur. Les pourcentages manuels de bilan ne remplacent pas ce calcul mensuel. Les minutes et présences sont comparées au mois précédent uniquement lorsque des données comparables existent ; aucune note de progression sportive n’est inventée.

Les données évoluent avec les sauvegardes existantes et restent dans le contexte du coach et de son équipe. Le rappel ne constitue pas une tâche serveur ni une notification lorsque le site est fermé.
