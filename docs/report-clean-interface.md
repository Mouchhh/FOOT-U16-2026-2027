# Interface Bilans épurée

Les contrôles secondaires et la barre de configuration d’équipe sont masqués uniquement dans Bilans. Une action rouge « Valider le bilan » reste disponible dans la barre inférieure sur chaque sous-onglet. Elle utilise le circuit existant de validation et de sauvegarde : en cas d’erreur, le bilan reste ouvert.

Le bouton Supprimer conserve son mécanisme de confirmation. L’export existant est regroupé dans Synthèse sous « Exporter le bilan ».

Les copies techniques « Copie locale avant ouverture · … » sont exclues des sélecteurs et propositions de reprise. Les données de récupération restent conservées ; aucun bilan enregistré n’est supprimé par ce nettoyage. Les messages de stockage et de validation en erreur restent visibles.

Le bandeau supérieur compact reste contenu dans l’écran à partir de 320 px, y compris dans les autres modules.

Vérification : tests navigateur dédiés au nettoyage, à la suppression, à la validation, aux règles joueurs et à la synchronisation Effectif.
